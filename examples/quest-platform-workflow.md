# Example: Quest Platform Integration Workflow

This example explains how a community quest platform would use the GenLayer Community Quest Moderator.

## Scenario

A community platform runs a quest:

"Create a post explaining how GenLayer can be used for community quest moderation."

The platform wants to avoid manually reviewing every submission and wants a transparent decision record.

## Step 1: Participant creates evidence

A participant creates a public evidence file or public post.
